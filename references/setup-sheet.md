# 收集端设置：Google Sheet（推荐）

目标：拿到一个能接收 POST 的 URL，数据直接落进**用户自己的**表格。
零第三方账号、零 API key、零月费。朋友拿去用就建他自己的表，互不相干。

一次性设置，大约两分钟。

---

## 为什么不能只给一个 Sheet 分享链接

用户经常以为「把表格链接给你就行」。不行：一个 Google Sheet 的分享链接是**只读展示地址**，
没有任何写入端点。要让网页往里写数据，必须由表格的所有者授权出一个写入接口。
Apps Script Web App 就是 Google 官方提供的、唯一不需要第三方服务的做法。

所以流程是：**用户给 Sheet 链接 → 引导他跑完下面 4 步 → 拿到 Web App URL**。
真正填进落地页的是 Web App URL，不是 Sheet 链接。

---

## 4 步

### 1. 打开脚本编辑器
在目标 Google Sheet 里：**扩展程序 → Apps Script**（英文界面是 Extensions → Apps Script）。

### 2. 粘代码
删掉编辑器里默认的 `function myFunction() {}`，把 `templates/apps-script.gs` 的**全部内容**粘进去，
按 Ctrl+S 保存。

### 3. 部署成网页应用
右上角 **部署 → 新建部署**：

| 字段 | 选什么 |
| --- | --- |
| 类型 | 网页应用 (Web app) |
| 执行身份 (Execute as) | **我 (Me)** |
| 谁有访问权限 (Who has access) | **任何人 (Anyone)** |

点「部署」。第一次会要求授权：
选自己的账号 → 出现「Google 尚未验证此应用」的警告 → 点**高级 (Advanced)** →
点**转至「未命名的项目」(不安全)** → 允许。

> 这个警告是正常的。它的意思是「这段脚本是你自己写的，没经过 Google 审核」，
> 而不是「这段脚本有问题」。脚本只能操作它所属的那张表。

### 4. 复制 URL
部署成功后会显示 **网页应用 URL**，长这样：

```
https://script.google.com/macros/s/AKfycb.................../exec
```

把它填进落地页 `CONFIG.endpoint`，`CONFIG.mode` 设成 `"sheet"`。

---

## 验证部署成功

浏览器直接打开那个 URL，应该看到：

```
waitlist endpoint is live
```

或者跑脚本验（跨平台，比 curl 稳）：

```bash
node scripts/preflight.mjs --endpoint "<你的 Web App URL>"
```

看到这行就说明通了。看到报错页说明第 3 步的「谁有访问权限」没选「任何人」。

## 常见坑

**改了代码没生效**
Apps Script 的部署是按版本冻结的。每次改完代码，要 **管理部署 → 编辑（铅笔图标）→
版本选「新版本」→ 部署**。只按 Ctrl+S 保存是不会更新线上版本的。

**表格里没出现 `waitlist` 工作表**
脚本会在第一次收到数据时自动建表并写表头。先去落地页提交一次测试数据。

**「任何人」访问会不会被灌垃圾**
会有这个风险，URL 泄露了任何人都能往里写。已经内置的防护：落地页有蜜罐字段，
机器人自动填充就会被静默丢弃。验证期流量本来就小，实际很少遇到。
真被刷了，最省事的做法是「管理部署 → 停用」，换一个新部署 URL。

**数据能不能导出**
它本来就在你自己的 Google Sheet 里，随便下载、随便接 Looker Studio、随便写公式。

## 表结构

脚本会自动建好这些列：

| 时间 | 事件 | 邮箱 | 现在怎么解决这个问题 | 来源 | 页面 | 浏览器 | 项目 |
| --- | --- | --- | --- | --- | --- | --- | --- |

`事件` 列有四种值，用它可以直接在表里算漏斗：

- `view` 有人看到了页面（每个会话只记一次）
- `cta_click` 点了 hero 区的主按钮
- `modal_open` 打开了留邮箱的弹窗
- `signup` 真的留下了邮箱
- `preorder_click` 点了预售按钮

**算转化率**：`signup` 行数 ÷ `view` 行数。对照 `references/copy-playbook.md` 里的 benchmark 判读。

## 备选：FormSubmit（零设置，但没有名单）

嫌上面 4 步麻烦，可以直接用 FormSubmit，**完全不需要注册**：

```js
endpoint: "https://formsubmit.co/你的邮箱",
mode: "formsubmit"
```

首次提交后会收到一封激活邮件，点一下就生效。之后每条 signup 直接进邮箱。

代价：**只有邮件，没有汇总名单，也没法算转化率**。适合先跑通流程，或者只想验证一两天。
想认真读数据还是用 Google Sheet。
