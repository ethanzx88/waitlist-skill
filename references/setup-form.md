# 收集端设置：表单端点

目标：拿到一个 URL，落地页把报名 POST 过去，你的邮箱收到通知。

两个选择，接口兼容，模板里都是同一行 `CONFIG.endpoint`：

| | Formspree | FormSubmit |
| --- | --- | --- |
| 要注册吗 | 要 | **不用** |
| 后台能看名单吗 | 能（最近 30 天） | 不能，只有邮件 |
| 每月额度 | **整个账户 50 条** | 官方未公布上限 |
| 反垃圾 | reCAPTCHA + 基础过滤 | reCAPTCHA |
| 限制来源域名 | 免费版就有 | 无 |

想要一个能看的后台就用 Formspree，想一秒钟搞定就用 FormSubmit。

---

## Formspree（推荐）

1. 去 https://formspree.io 注册（免费）
2. 新建一个 Form，设好接收通知的邮箱
3. 拿到端点，形如：

```
https://formspree.io/f/xxxxxxxx
```

4. 填进落地页的 `CONFIG.endpoint`
5. 在表单设置里打开 **Restrict to domain**，填你的 `*.vercel.app` 域名。
   这样别人扒走你的端点也灌不进来，而且免费版就有这个功能

验证：

```bash
node scripts/preflight.mjs --endpoint "https://formspree.io/f/xxxxxxxx"
```

### 免费版的限制，要提前跟用户讲清楚

**每月 50 条是整个账户共享的，不是每个表单 50 条。**
官方文档那一页的标题就叫 "Account limits"，原文是「每个方案都包含无限表单和无限项目」，
但提交额度只有一个。所以你同时跑三个验证页，就是三个页面分这 50 条。

其他免费版限制：

- **提交存档只有 30 天**，更早的记录从后台消失
- **不能导出**（没有 CSV 导出，没有搜索，没有 API）
- 通知邮箱最多绑 2 个
- 硬性速率限制：**每分钟 20 次提交**，超了 AJAX 返回 429
- **超过月度 50 条之后会发生什么，Formspree 全站文档没有写**。
  只说会在 50% / 75% / 90% 和超限时给你发通知。所以别踩线，到 40 条就该动了

付费档：Personal **$10/月** 200 条、Professional **$20/月** 2K 条、Business **$60/月** 20K 条。

### 两条必须做的防护

**1. 在邮箱里建个过滤规则**，把 Formspree 的通知邮件自动打标签存档。
后台那 30 天会过期，但你邮箱里的邮件不会。这是你唯一的完整备份。

**2. 用量到 40 条就处理**：要么升 Personal，要么临时换一个新表单端点分流。

## FormSubmit（零注册）

不想注册账号就用这个：

```js
endpoint: "https://formsubmit.co/你的邮箱"
```

首次提交后会收到一封激活邮件，点一下才生效。之后每条报名直接进邮箱。

代价：**没有后台，没有汇总名单**。所有数据只存在于你的收件箱。

## 想算转化率的话

报名数你有了（数邮件），但**访客数**需要另外一个来源。
不要用表单端点做浏览埋点，一千次曝光就是一千条提交，Formspree 的 50 条一天就没了。

正确做法是用 **Vercel Web Analytics**，免费版就够：

1. Vercel 后台 → 项目 → **Analytics** → 点 **Enable**
2. 它会给你一段 `<script>`，**路径是这个项目专属的**，每个项目都不一样，
   所以模板里没法预置。把它粘到 `index.html` 的 `</head>` 之前
3. 重新部署一次

之后 **转化率 = 报名数 ÷ Analytics 里的 visitors**，判读标准见 `copy-playbook.md`。

Hobby 免费版给 **5 万 events/月、1 个月数据保留**，验证阶段绰绰有余。
注意自定义事件（custom events）是 Pro 以上才有的，所以免费版只能拿到访客数和浏览量，
拿不到「点了哪个按钮」。够用了。
